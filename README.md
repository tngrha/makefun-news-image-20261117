A Python program (stdlib + PIL only) that draws a 1024x1024 newspaper front page summing up the world news of Tuesday 17 November 2026 and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`. Masthead names the day; hero: Ukraine's strike collapses part of the Kerch Bridge to Crimea; eight story tiles cover Trump in Manila and China, the Hormuz tanker mines and the US carrier, Iran's drone attack in Bahrain, the JPMorgan outage and Nvidia earnings, the failed Vulcan rocket, the Pentagon's 9th failed audit, UK sanctions on Israeli firms, and Japan scrambling jets; footer "Also in brief": Depardieu's guilty plea, congenital measles cases, and the Houthi advance in Yemen. Deterministic, no network, no randomness — repeated runs are byte-identical.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
